# Provisional Cochrane Data

This folder contains script-generated, AI-assisted, or otherwise unaudited TSV/JSON files used for triage and manual inspection.

These files are not final benchmark data. Use them to inspect reviews, plan curation work, and seed manual audit tables. Before public release or paper analyses, relevant rows and fields should be verified against the Cochrane review PDFs and source reports, then copied or promoted into `../verified_data/`.

Most files here are regenerated by the helper scripts in `../scripts/`. Manual edits are okay during auditing, but keep in mind that rerunning a script may update mechanical columns or add rows for newly added PDFs.

Current files:

- `review_curation_summary.tsv`: review-level triage and curation context.
- `review_protocol_eligibility.tsv`: AI-prefilled, unverified research question, objective, population and intervention eligibility, and inclusion/exclusion fields.
- `review_outcomes.tsv`: provisional outcome rows derived from saved Cochrane forest-plot analysis results, with short `outcome_name` labels and links to the contributing saved analysis-result rows.
- `review_domain_source_raw.json`: raw domain-relevant metadata extracted from the Cochrane PDFs, including editorial group and Index Terms/MeSH fields when found.
- `review_domain_labels_ai.json`: AI-generated, unverified clinical-domain labels derived from `review_domain_source_raw.json`.
- `analysis_counts.tsv`: heuristic scan of Cochrane `Analysis X.Y` entries.
- `study_characteristics_first_pass.tsv`: provisional first-pass study-characteristics rows extracted from Cochrane `Characteristics of included studies` PDF tables.
- `study_characteristics_first_pass_raw.json`: raw block text, labeled sections, and normalized study-characteristics JSON for the same first-pass rows.
- `analysis_results_first_pass.tsv`: provisional first-pass per-analysis result rows with cleaned/canonical comparison labels and overall CI fields when a clear total row or single candidate CI is detected.
- `analysis_results_first_pass_raw.json`: raw selected analysis-block excerpts and candidate effect/CI patterns for the same first-pass rows.
- `analysis_comparisons_first_pass.tsv`: provisional first-pass comparison families, automatic comparison-role labels, cleaned/canonical comparison labels, and parsed comparison arms derived from saved analysis-result rows.
- `analysis_study_rows_first_pass.tsv`: provisional first-pass forest-plot study rows, cleaned/canonical comparison labels, matched reference blocks, per-arm data, weights, study-level effects, and PMID/PMCID coverage.
- `analysis_study_rows_first_pass_raw.json`: selected raw analysis-block excerpts used to audit the forest-plot study-row extraction.
- `analysis_risk_of_bias_rows_first_pass.tsv`: provisional first-pass row-level risk-of-bias symbols parsed from Cochrane forest-plot RoB columns and aligned to extracted forest-plot study rows by analysis ID and study order.
- `analysis_risk_of_bias_rows_first_pass_raw.json`: per-analysis RoB symbol blocks, legends, extraction statuses, and source excerpts used to audit the row-level RoB extraction.
- `analysis_reproduced_results_first_pass.tsv`: provisional first-pass reproduction checks for each saved analysis using `all_studies` and `pmcid_only` subsets, carrying the cleaned/canonical comparison labels and CI IoU against the Cochrane-reported overall CI forward.
- `analysis_reproduced_forest_plots_first_pass.json`: structured forest-plot payloads for the reproduced totals shown in the audit website.
- `pubmed_pmc_summary.tsv`: review-level PubMed/PMC indexing summary generated from PubMed HTML reference blocks.
- `included_study_indexing.tsv`: included-study reference-block indexing details generated from PubMed HTML.
- `included_report_indexing.tsv`: report-candidate-level PubMed/PMC lookup details within included-study reference blocks.
- `included_trial_registry_records.tsv`: registry-record details extracted from included-study reference blocks.
- `included_pubmed_records.tsv`: PMID-level matched record details.
- `excluded_study_indexing.tsv`: excluded-study reference-block indexing details generated from PubMed HTML.
- `excluded_report_indexing.tsv`: report-candidate-level PubMed/PMC lookup details within excluded-study reference blocks.
- `excluded_pubmed_records.tsv`: PMID-level matched excluded-reference records used as evaluation-only negative benchmarks when present.
- `excluded_trial_registry_records.tsv`: registry-record details extracted from excluded-study reference blocks.
- `excluded_pubmed_summary.tsv`: review-level PubMed/PMC coverage counts for excluded-study references.
- `reference_indexing_source_manifest.json`: source/provenance manifest for the active reference-indexing artifacts.

The `*_first_pass.*` files intentionally cover only reviews whose `review_group` is `first_pass`. Rerun the corresponding scripts with a different `--group` and output path when you are ready to audit other groups.
