# Cochrane Audit Site

Static, read-only audit dashboard for provisional Cochrane review curation outputs.

Live site: https://qingfangliu.github.io/cochrane-audit-site/Cochrane_reviews/audit_site/

This repository is a public mirror of selected audit-site files and provisional data exported from the private working repository. The dashboard is intended for review, checking, and sharing of current curation outputs.

The data are provisional and may include AI-assisted labels or extracted fields that have not yet been manually verified.
